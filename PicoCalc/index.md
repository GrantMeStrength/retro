# PicoCalc

## Stand

Here's a basic stand for the PicoCalc, holding it at 45' in a quite stable way. Not perfect by any means, but it works. I printed it on a Bambu A1.

In this folder: a link to the Tinkercad project (please make it better!) and STL file for printing.
